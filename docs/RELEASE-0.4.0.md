# DualBoot Setup 0.4.0 — experimental

Inclui menu com resposta rápida de 180 ms, ícones transparentes, cache e transferência parcial do fundo; assistente de Secure Boot; silenciamento conservador da mensagem de checksum correto; pacote separado de ferramentas SteamOS para vídeo e diagnóstico.

Baixe `DualBoot-Setup-0.4.0.exe` para Windows ou o ZIP com os manuais. Para os auxiliares Linux, use `DualBoot-SteamOS-Tools-0.4.0.zip`. Compare os três arquivos com `SHA256SUMS-0.4.0.txt`.

- Manual simples: `INSTALADOR.md`.
- Assinatura local, MOK e BIOS: `SECUREBOOT.md`.
- Novidades e limites: `ATUALIZACOES-0.4.0.md`.
- Ferramentas opcionais: `extras/steamos/README.md`.

A versão é experimental. Não altera o boot existente durante a publicação e não contém chaves, certificados pessoais, kernels, dumps, relatórios particulares ou filmes comerciais. O fluxo completo do EXE e a mudança de saída em hardware continuam dependendo de testes físicos próprios.
